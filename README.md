# Spikeproof downloads

Installers for [Spikeproof](https://spikeproof.dev): design API journeys, record browser flows,
and run real k6 performance tests on your own machine.

**[Download the latest version →](https://github.com/huntermacias/spikeproof-releases/releases/latest)**
(or use [spikeproof.dev/download](https://spikeproof.dev/download))

| Platform | File |
| --- | --- |
| macOS (Apple Silicon) | `Spikeproof-<version>-mac-arm64.dmg` |
| Windows (x64) | `Spikeproof-Setup-<version>.exe` (or the portable `.zip`) |

## Beta builds are unsigned

Beta releases aren't signed with an Apple or Microsoft certificate yet, so your computer asks you to
confirm the first time you open the app. Each release includes `INSTALL-BETA.md` with the steps,
and `SHA256SUMS.txt` so you can check that the download is intact.

## Reporting problems

Open an [issue](https://github.com/huntermacias/spikeproof-releases/issues) with your OS version,
the Spikeproof version, and what happened.

This repository only hosts installers. The source code is private.
